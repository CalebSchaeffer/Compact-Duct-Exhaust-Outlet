# Compact Duct Exhaust Outlet
My final project for ENGR 1304 (Graphics). It was a 3d printable 4-inch exhaust outlet that took a circular input and transitioned it into a rectangular exhaust. Flaps were also in place to prevent stuff from getting in while the fan is off. 

This project was completed earlier in my CAD experience. My skills have improved since then, but expect some of the CAD to be a bit rough.
